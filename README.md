# Sample Tic Tac Toe Variants

This repository contains three progressively enhanced Tic Tac Toe versions.

## Versions

- **v1 - Basic 2-Player** (`versions/v1`)
  - 3x3 board
  - Two local players (X and O)
  - Win/draw detection
  - New game button

- **v2 - Match Tracker** (`versions/v2`)
  - Everything in v1
  - Running scoreboard for X, O, and draws
  - Highlighted winning line
  - Turn-aware status banner

- **v3 - Smart Opponent** (`versions/v3`)
  - Everything in v2
  - Play vs human or unbeatable AI
  - Move history timeline
  - Theme toggle (light/dark)

## Run locally

Open any version's `index.html` in your browser.

Examples:

- `versions/v1/index.html`
- `versions/v2/index.html`
- `versions/v3/index.html`
