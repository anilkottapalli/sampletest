# Sample Tic-Tac-Toe (Multiple Versions)

This repo includes three independent Tic-Tac-Toe samples to show feature progression:

1. **Version 1 (Basic):** local 2-player game with win/draw detection.
2. **Version 2 (Scoreboard):** tracks wins/draws and round history.
3. **Version 3 (AI + Extras):** adds CPU opponents (random/hard), theme toggle, and undo support for PvP.

## Run locally

```bash
python3 -m http.server 8000
```

Then open:

- `http://localhost:8000/index.html`
