# Sample Tic-Tac-Toe Variants

This project includes **three versions** of Tic-Tac-Toe, each with progressively richer features.

## Versions

1. **Version 1 (`versions/v1-basic.html`)**
   - Two-player local game
   - Win/tie detection
   - Restart button

2. **Version 2 (`versions/v2-scoreboard.html`)**
   - Everything in V1
   - Running scoreboard (X wins, O wins, ties)
   - "Next round" keeps scoreboard while clearing board

3. **Version 3 (`versions/v3-ai-theme.html`)**
   - Human vs computer (simple AI)
   - Difficulty modes: Easy (random), Hard (minimax)
   - Light/Dark theme toggle
   - Match statistics + reset controls

## Run

Open `index.html` in a browser.

If you have Python installed, you can also serve locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
